## Memory and Learning

**Before starting ANY task:**
1. Read `Learnings.md` in full
2. Summarize it in 3–5 bullet points out loud
3. Apply all "What Has Worked" and "Patterns" entries
4. Avoid everything in "What Has Failed"

**After completing ANY task (NON-OPTIONAL):**
Update `Learnings.md` with this exact format:

**[Date] — [Task type]**
- Observation: [specific thing you noticed]
- Action: [what to do or avoid going forward]
- Confidence: [high / medium / low]

Rules for entries:
- Be SPECIFIC. "Avoid relative imports in /utils — build step fails" is good. "Be careful with imports" is useless.
- Only add project-specific learnings, not general best practices
- Do NOT duplicate existing entries
- You MUST update Learnings.md before ending the session, even if nothing new happened — write "existing patterns held"
